# Changelog

## 0.1.0 — first public release

- Daily, weekly and monthly ToDo lists with rollover review, postpone,
  recurring tasks, deadlines and reminders.
- Goals (measurable and log) with sub-goals and derived progress.
- Habits with a weekly heat-map grid.
- Background-safe Pomodoro timer with work/break presets.
- Journal and review notes per day, week and month.
- Plan and review reminders (day, week, month).
- All data stored as Markdown files with YAML frontmatter in a folder you
  choose, ready for Syncthing and Obsidian.
